# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately. Do not open a public issue or pull request for security problems.

Send your report to **cloud_core@idealo.de**.

Please include:

- a description of the vulnerability and its potential impact,
- the affected version(s) or commit,
- steps to reproduce or a proof of concept, if available.

We will acknowledge your report, keep you informed about the progress of a fix,
and credit you if you wish once the issue is resolved.
